# Doctor-Patient Management API

A production-ready RESTful backend application built with **FastAPI** for managing doctors, patients, authentication, authorization, and doctor-patient assignments.

## 🚀 Features

- JWT-based authentication
- User registration and login
- Role-based authorization
- Admin and Doctor roles
- Doctor management
- Patient management
- Doctor-patient assignment
- Soft delete for doctors
- Input validation using Pydantic
- SQLite database using SQLAlchemy
- Automatic Swagger/OpenAPI documentation
- Protected API endpoints
- Password hashing
- Health check endpoint

---

## 🛠️ Tech Stack

- **Python 3.9+**
- **FastAPI**
- **SQLAlchemy**
- **SQLite**
- **Pydantic**
- **JWT**
- **Passlib / Bcrypt**
- **Uvicorn**
- **Python-dotenv**
